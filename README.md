This is a [Next.js](https://nextjs.org) project for KIA financing, forked from hcfi-credit-sims.

The public homepage design is on hold until KIA/Hyundai design guidelines arrive. Simulation, CMS, admin, and dealer portal reuse the HCFI engine with a KIA Confins brand filter.

Dev server runs on port **3071** so it can run alongside the Hyundai site on 3070.

```bash
npm run dev
```

Open [http://localhost:3071](http://localhost:3071).
